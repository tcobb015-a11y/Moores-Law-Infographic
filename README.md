# Moore's Law Interactive Infographic

This project is an interactive infographic about Moore's Law and the rapid growth of transistor counts in computer chips.

## Interaction

Click any year on the timeline to:
- reveal information about that milestone,
- see the transistor count,
- compare it with Intel's 1971 4004,
- and open the original source.

The infographic also includes a logarithmic bar chart showing how transistor counts grew from thousands to billions.

## Files

- `index.html` — webpage structure and written content
- `style.css` — visual design and mobile layout
- `script.js` — timeline data and interactivity

## How to publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the top level of the repository.
3. Commit the files.
4. Open the repository's **Settings**.
5. Choose **Pages** in the left sidebar.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)` folder.
8. Save.
9. GitHub will display the public Pages URL after deployment.
